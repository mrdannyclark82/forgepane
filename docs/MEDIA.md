Release media: the 26-second demo (`forgepane-demo.mp4`) and screenshots
(`screenshot-editor.png`, `screenshot-welcome.png`) are attached to the
v0.1.0 release. The API token used to publish cannot itself upload assets
(uploads.github.com rejects its credentials, 401), so release files are
attached from a signed-in GitHub web session. That is how v0.1.0's assets
landed, and how the v0.2.0 tarball attaches too.
